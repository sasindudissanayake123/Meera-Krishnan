🍰 Bakery Portfolio Website

A modern and responsive bakery portfolio website designed to showcase bakery products, custom cakes, services, and business information. This project provides an attractive user interface for customers to explore bakery offerings and learn more about the business.

📌 Features

* Responsive homepage design
* Featured cake and bakery product showcase
* About Us section
* Product gallery
* Contact section
* Clean and modern user interface
* Mobile-friendly layout

🛠️ Technologies Used

HTML5 – Structure and content of the website
CSS3 – Styling, layout, and responsive design

🚀 Getting Started

1. Clone the Repository

```bash
git clone https://github.com/your-username/bakery-portfolio.git
```

2. Open the Project

Navigate to the project folder and open `index.html` in your preferred web browser.

```bash
cd bakery-portfolio
```
